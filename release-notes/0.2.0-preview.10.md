Preview 10 lets MCP snippets ask the decision engine typed questions and rerank long results before the model reads them, moves workflow `decide()` to the same question shape, the one OpenAI Decisions uses, and fixes subscription image generation after GPT-5.5 retired from Codex.

> [!WARNING]
> **If your workflows call `decide()`, rewrite their questions when you update.** Questions are now a list instead of a map keyed by ID, so each question names itself with `name`. `noul` questions become `predicate` questions, and `criteria` becomes `choices` for a choice and `levels` for a score. Answers come back as `answers`, a list in question order, and `by_name`, keyed by name, and a predicate's probability is now in `probability` rather than `noul`. A workflow that still passes the old shape fails at its first `decide()` call with a catchable error, and so does a run started before the update when you resume it, even at a call it had already answered. See [Typed decisions](https://caudra.ai/docs/workflows/#typed-decisions).

### MCP

- **Decisions and reranking in snippets.** With the decision engine on, an `mcp` snippet can call `decide()` for typed answers about its data, and `rerank()` to keep only the candidates relevant to a query, best first, for up to 256 candidates. A snippet can rank 200 issue titles and return the ten that matter, so the rest never reach the model. Calls need no approval, work in plan mode, show as rows on the card, and appear in the decision log under the feature `mcp`. See [Decisions and reranking](https://caudra.ai/docs/mcp/#decisions-and-reranking).
- **Decision answers you can read at a glance.** A `decide()` row on the `mcp` card shows its verdicts on one line, and always shows each question below it with a bar per option, the likeliest highlighted, and a warning when the winner is uncertain. A `rerank()` row always shows the candidates it kept, best first, under the labels they were given. Click the row's footer to see the JSON the snippet received; selecting any part of the row copies that JSON, in either view. In `/decisions`, Recent draws logged answers the same way, and `j` switches them to JSON.

### Workflows

- **`decide()` takes OpenAI Decisions questions.** A choice option or a score level can carry a description, as a map with `value` or `label` and `description`, and each answer lists the probability of every option or level. Both decision protocols return the same shape. `rerank()` is unchanged.

### Image generation

- **ChatGPT subscription image generation uses a supported model.** Image requests now run through GPT-6.1 Sol instead of GPT-5.5, which OpenAI retired from Codex with ChatGPT sign-in on October 14. This fixes the unsupported-model error without changing your configured image model or switching to API billing.
