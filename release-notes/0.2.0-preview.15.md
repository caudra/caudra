- Matt Pocock's engineering skills ship as an opt-in pack beside pstack.

### Changes

- **mattpocock skills**: `[plugins.skill] mattpocock = true` adds 16 of [Matt Pocock's skills](https://github.com/mattpocock/skills), translated for Caudra, as the `mattpocock` skill and a `/mattpocock:<name>` command for each. They cover grilling a plan, domain modeling, test-first building, diagnosing bugs, code review, specs and tickets, and handoffs. Grilling asks through the `question` tool, and switching the pack applies at once in the terminal UI. Both packs can be on together. See [mattpocock](https://caudra.ai/docs/skills/#mattpocock).
