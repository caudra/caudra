- Model lists reflect retired OpenAI and Copilot models, with corrected prices and limits for Mistral, Z.AI, and DeepSeek.
- Matt Pocock's engineering skills ship as an opt-in pack beside pstack.
- The main agent can guide or redirect a running task without stopping it.
- Source analysis attributes Go and Rust initializer calls more accurately.
- File watching on macOS no longer hangs when folders are watched and unwatched in quick succession.

### Models

- **OpenAI model list updated.** Retired GPT-4.1 Nano and o4-mini entries are removed. The `gpt-5.6` alias uses GPT-5.6 Sol metadata.
- **Copilot retirements reflected.** GPT-5 mini, GPT-5.4 mini, GPT-5.4, GPT-5.5, and Gemini 3.7 Flash are removed from the built-in list after their October 19 retirement.
- **Mistral GLM Flash and cached-input prices.** `zai-glm-5-3-flash` has its own vision-capable entry and pricing instead of matching the larger GLM model. Cached input now uses the published rates for Mistral Medium, Mistral Small, and Ministral 14B.
- **Z.AI FlashX pricing.** `glm-4.7-flashx` has its own paid rates instead of inheriting the free Flash model's pricing.
- **DeepSeek output allowance corrected.** DeepSeek Flash and V4 Pro use the full 393,216-token output limit instead of 384,000.

### Changes

- **mattpocock skills**: `[plugins.skill] mattpocock = true` adds 16 of [Matt Pocock's skills](https://github.com/mattpocock/skills), translated for Caudra, as the `mattpocock` skill and a `/mattpocock:<name>` command for each. They cover grilling a plan, domain modeling, test-first building, diagnosing bugs, code review, specs and tickets, and handoffs. Grilling uses `question` and respects deferred answers. Reviews include the requested uncommitted work and can use the session plan as a spec. Drafts preserve that plan, handoffs distinguish pending work from verified results, and publishing can use your configured MCP or CLI connection. Switching the pack applies at once in the terminal UI, and both packs can be on together. See [mattpocock](https://caudra.ai/docs/skills/#mattpocock).
- **Guide running tasks**: `task_control` `guide` lets the main agent send a running task changed requirements or a reply to its report. The task reads it at its next step, and `interrupt: true` replaces its current turn instead. The message waits in the task chat's queue like your own guidance. Guidance a task never reads comes back with its result. See [Inspect and control tasks](https://caudra.ai/docs/sessions/#inspect-and-control-tasks).

### Source analysis

- **More accurate references.** Go grouped package declarations keep separate spans, so an initializer call belongs to the variable or constant that contains it. Calls in local Go and Rust initializers stay attached to the enclosing function or method.

### Fixes

- **Fresh context after compaction**: Compaction refreshes system reminders immediately, including after a long idle. It no longer replays outdated environment, memory, and model notices only to correct them on your next message.
- **Steadier file watching on macOS.** Watching and unwatching folders in quick succession no longer hangs the watcher.
