# Model favorites

The models the user marked as favorites, newest first. When the user names a model for a task,
`model` resolves to the favorite that matches the name before any other model, so read the user's
model names against this list. `lane` is the size class Caudra gives a model, `jobs` are the model
jobs the user bound to it, and `thinking` lists the levels a task's `thinking` snaps to.
