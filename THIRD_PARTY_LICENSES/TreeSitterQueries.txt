Tree-sitter origins of the seventeen ripwire-derived Workcell query sets

Local directory: workcell/crates/source-languages/queries/<query>/tags.scm.
Ripwire's Apache-2.0 license is in Ripwire.txt. This file preserves the MIT
licenses of the upstream grammars identified in the query headers and in
ripwire's THIRD_PARTY.md at 255dc199c54e4c6c43e25b26a713154a84efd6ae.
Each license below was checked against its pinned upstream source and the
corresponding third_party/deps/<grammar>/LICENSE in that ripwire snapshot.

These are query-origin versions, which can differ from the grammar crates
resolved by Cargo.lock. Some queries use upstream tags.scm, while others were
written against grammar node types. Swift and TypeScript headers omit versions,
so their notice sources use the inspected ripwire snapshot's grammar pins.
The original ripwire import revision remains unrecorded. See Ripwire.txt.
