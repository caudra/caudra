01 / CAUDRA

What Caudra adds.

Compared with its Maki foundation, Caudra focuses on durable work, safe intervention, and evidence-backed completion. Read the full comparison and rationale.

01.1

Evidence-gated completion

Set a completion condition with /goal. A private evaluator checks the recorded evidence and continues the run when the condition is unmet.

01.2

Durable task agents

Task agents keep stable IDs, separate transcripts, queued guidance, and histories that continue across turns and restored sessions.

01.3

Guide, queue, or replace

Redirect active work at a safe boundary, schedule the next run, or replace a run without losing the rest of the queue.

01.4

Branchable sessions

Fork from a message and restore conversation state, workspace files, or both while preserving the abandoned path.

01.5

Bound permission authority

Reusable approvals bind to validated input, typed resources, implementation identity, authority, and an explicit lifetime.

01.6

Decoupled Workcell tools

Workcell owns protocol-neutral contracts, validation, execution bounds, atomicity, network policy, and process cleanup. Caudra binds permissions, retained output, and presentation.

01.7

Source-faithful Markdown

Read Unicode maths and Mermaid diagrams, pan wide charts, follow validated links, and copy the original Markdown behind rendered cells.

01.8

Mouse across native controls

Use pickers, queues, footer controls, task cards, links, and message actions with matched press-and-release behavior that preserves drag selection.
