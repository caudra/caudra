Caudra is the complete coding agent for your terminal. Steerable subagents, built-in token savings, a workbench, and a history you can revert ship together in one native binary, and you stay in control of models, tools, and subagents. Caudra is an independent fork written in Rust. The first public release is 0.2 Preview.

Inside Caudra, `/docs` opens these pages for the version you run, and `/` searches every page.

You can also ask the agent. When you ask how to use or configure Caudra, it loads the built-in [`caudra-docs` skill](/docs/skills/#caudra-docs) and answers from these pages as they were when your binary was built. It reads only the sections it needs.

Something missing or wrong? Open an issue on [GitHub](https://github.com/caudra/caudra).
